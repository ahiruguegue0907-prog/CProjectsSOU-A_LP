あなたは、優秀な日本語UI/UXデザイナー兼フロントエンドエンジニアです。
Next.js + TypeScript + Tailwind CSS で、やさしく信頼感のある日本語ランディングページを1ページ構築してください。

【プロジェクト概要】
サービス名：SOU-A
タグライン：親子の時間をひらく、やさしいAI体験

このサービスは、
「AIに苦手意識があるけれど、子どもを喜ばせたい」
「AIを子どもにいきなり渡すのは不安」
と感じている母親向けの入口サービスです。

重要なのは、
“子どもが一人でAIを使うサービス” ではなく、
“母親がAIを使って、親子の時間をつくるためのサービス”
として見せることです。

【ページの目的】
1. 共感を得る
2. SOU-Aの価値を伝える
3. note・無料ガイド・体験会への導線を作る

【絶対に守る方針】
- 子どもの単独利用を前提に見せない
- 子ども向けAIチャットボットのLPのようにしない
- 「完全安全」「絶対安全」「100%安全」などの断定表現は禁止
- 価格表、ログイン、会員登録、アプリDL訴求は不要
- テック感を出しすぎず、母親が安心できる温度感にする
- 母親を責めるニュアンスを入れない
- やさしい、清潔、信頼感、少し希望があるトーンにする

【デザイン方針】
旧サイトのデザインDNAは活かしてください。
ただし、子ども向けAIプロダクト感は弱めて、母親向け・親子向けの入口LPに再構成してください。
