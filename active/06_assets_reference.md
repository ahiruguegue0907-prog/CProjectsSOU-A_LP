# SOU-A / Assets Reference

## 方針
旧サイトのスクリーンショットや資料は、
「思想」「配色」「余白感」「カードUI」を引き継ぐための参考として使う。

ただし、子ども向けAIチャットボットのLPとして見えてしまう要素は前面に出さない。

## activeで参照したい画像
以下のような名前にリネームして assets フォルダに入れることを推奨する。

1. hero_old_grid.png
- 旧トップのヒーロー部分
- 参考にしたい点：余白、方眼グリッド、青緑の世界観
- 参考にしない点：子ども向け直利用の印象

2. manifesto_old.png
- 旧マニフェストセクション
- 参考にしたい点：思想の見せ方、信頼感、タイポグラフィ

3. features_old_cards.png
- 旧3機能やカードUIのスクショ
- 参考にしたい点：カードの形、色の使い分け、やさしい図解感

4. safety_old_dark.png
- 旧安全設計セクション
- 参考にしたい点：重厚感ではなく整理されたカード設計のみ
- 参考にしない点：「絶対的」「完全」などの強い訴求

5. final_message_old.png
- 旧ラストメッセージ部分
- 参考にしたい点：静かな締め方、余白の使い方、ブランドの誠実さ

## activeでは使わない方がいい画像
- 子ども単独チャット画面を主役にしたスクショ
- 年齢別モードの詳細を前面に出した画面
- 料金表
- ログイン画面
- 子ども用プロダクトに見えるUIの中心部分

## PDF資料の扱い
PDFは archive に置く。
active にはPDF全文を入れず、必要な部分だけ要約したMarkdownを置く。

## 画像の命名ルール
可能なら英数字 + ハイフン or アンダースコアにそろえる。
例：
- hero_old_grid.png
- manifesto_old.png
- features_old_cards.png

日本語ファイル名でも使えることは多いが、
実装AIや参照のしやすさを考えるとシンプルな英数字名が望ましい。
