# SOU-A / LP Structure

## 1. ヘッダー
目的：
- サービス名を認識してもらう
- 安心感のある入口をつくる
- 主要導線をわかりやすく置く

要素：
- ロゴ：SOU-A
- ナビ：できること / はじめ方 / 開発者の想い / 安心への考え方 / note
- CTA：無料ガイドを受け取る

## 2. ファーストビュー
目的：
- 一目で「私向けかも」と思ってもらう
- AIが苦手でも関係あると感じてもらう

見出し候補：
AIってむずかしそう。
でも、子どもを笑顔にする使い方なら、今日からできる。

サブコピー：
SOU-Aは、AIに詳しくないお母さんでも、
子どもと一緒に音楽・お話・イラストを楽しめるようになる
“親子AI体験”の入り口です。

CTA：
- 親子AI体験の例を見る
- 無料ガイドを受け取る

## 3. 共感セクション
見出し：
こんなモヤモヤ、ありませんか？

カード：
1. AIが気になるけど、何から始めればいいかわからない
2. 子どもを喜ばせたいけど、時間も余裕もない
3. AIを子どもにどう触れさせるべきか不安

## 4. 価値提案セクション
見出し：
SOU-Aが目指すのは、
AIを“子どもに渡すこと”ではなく、
お母さんが“親子の時間に変えること”です。

価値：
1. 子どもを喜ばせる体験がつくれる
2. お母さん自身の負担も少し軽くなる
3. AIとのちょうどいい距離感がわかる

## 5. できることセクション
見出し：
親子でできる、はじめてのAI体験

カード：
- 親子AIミュージック
- 親子AIおはなし
- 親子AIキャラクターづくり
- しんどい日のアイデア相談

## 6. はじめ方セクション
見出し：
むずかしいことは、しなくて大丈夫。

ステップ：
1. やってみたい体験を選ぶ
2. ガイドに沿ってAIに聞くだけ
3. 子どもと一緒に楽しむ

## 7. 開発者の想い
見出し：
我が子に、正しいAIの使い方を正しく教えたい。
そこから、SOU-Aは始まりました。

内容：
- 旧「AIせんせい」開発の経緯
- 途中で止めた理由
- 母親向け入口に切り替えた理由
- 2児の母としての視点

CTA：
noteを見る

## 8. 安心への考え方
見出し：
安心して向き合うために、大切にしていること

項目：
1. 子どもを一人でAIに向かわせない
2. AIを“正解の箱”にしない
3. 創り手への敬意を忘れない
4. 誇張しない

## 9. 今後の展望
見出し：
しんどい日のお母さんにも、寄り添える形を考えています

内容：
- 母親向けAI伴走機能は構想中
- 主役ではなく未来の展望として控えめに見せる

CTA：
先行案内を受け取る
